# Deaz Rental Website Clone Summary

## Target Website
- **URL:** https://deazrental.com/
- **Business:** Deaz Rental Mobil Banjarmasin & Banjarbaru
- **Contact:** +6281255964566 / info@deazrental.com

## Tech Stack
- **Framework:** Next.js 16 (App Router, React 19, TypeScript strict)
- **Styling:** Tailwind CSS v4 with custom keyframes & shimmer animations
- **Typography:** Google Fonts `Overpass` (weights 100-900)
- **Icons:** Lucide Icons (lucide-react & SVG integrations)
- **Data:** Clean JSON structures for car fleet, services, and locations

## Key Features & Interactivity
- **Responsive Navigation:** Fixed navbar with smooth hamburger animation and mobile drawer
- **Fleet Showcase:** 16 vehicles with hover animations and custom WhatsApp pre-filled booking messages
- **Customer Documentation Gallery:** Smooth-scrolling horizontal snap carousel with interactive fullscreen Lightbox (Arrow navigation & Escape key support)
- **Floating Contact Widget (FAB):** Expandable bottom-right widget with one-click WhatsApp, Phone, Instagram, and Facebook buttons
- **Google Maps Integration:** Embedded interactive map for Banjarmasin location
